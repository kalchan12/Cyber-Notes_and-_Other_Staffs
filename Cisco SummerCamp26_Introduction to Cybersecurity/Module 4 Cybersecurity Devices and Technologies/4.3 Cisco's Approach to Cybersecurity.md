
## **4.3.1 Cisco's CSIRT (Computer Security Incident Response Team)**

A **CSIRT** is a specialized team responsible for handling cybersecurity incidents. Their role goes beyond responding to attacks—they also work to prevent future incidents through planning, monitoring, and collaboration.

### What CSIRT Does

- Receives and investigates security incident reports.
- Responds to cyber attacks and minimizes damage.
- Performs threat analysis and mitigation planning.
- Reviews security architecture to improve defenses.
- Shares intelligence with other security organizations.

### Cisco CSIRT

Cisco's CSIRT collaborates with international security organizations such as:

- **FIRST** (Forum of Incident Response and Security Teams)
- **NSIE** (National Safety Information Exchange)
- **DSIE** (Defense Security Information Exchange)
- **DNS-OARC** (DNS Operations Analysis and Research Center)

This collaboration helps Cisco stay updated on the latest threats and best practices.

### Key Takeaway

A CSIRT combines **incident response, threat intelligence, and proactive security planning** to reduce organizational risk.

# **4.3.2 Security Playbook**

A **Security Playbook** is a documented guide that explains how an organization prepares for, responds to, and recovers from cybersecurity incidents.

### A security playbook should include:

- **Risk Identification**
    - Identify systems, assets, and data that require protection.
- **Preventive Measures**
    - Implement security controls and provide employee security training.
- **Incident Response Plan**
    - Define the steps to contain and recover from security incidents.
- **Post-Incident Recovery**
    - Restore systems, improve security measures, and prevent similar attacks.

### Key Takeaway

A security playbook ensures everyone knows **what to do before, during, and after** a cyber attack.


# **4.3.3 Tools for Incident Detection and Prevention**

Organizations use multiple security tools to detect, prevent, and respond to cyber threats.

### Common Security Tools

- **Firewall** – Filters network traffic.
- **IDS (Intrusion Detection System)** – Detects suspicious activity.
- **IPS (Intrusion Prevention System)** – Detects and blocks attacks.
- **SIEM** – Collects and analyzes security logs.
- **DLP (Data Loss Prevention)** – Prevents sensitive data from leaving the organization.
- **Antimalware** – Detects and removes malicious software.

### Key Takeaway

No single tool provides complete protection. Organizations combine multiple security technologies for layered defense.

# **4.3.4 Cisco ISE and TrustSec**

Cisco provides security solutions that control who can access network resources.

### Cisco Identity Services Engine (ISE)

Cisco **ISE** manages user identities and authenticates devices before granting network access.

**Functions:**

- Authenticates users and devices.
- Applies security policies.
- Controls network access.

### Cisco TrustSec

**TrustSec** enforces **role-based access control (RBAC)**.

Instead of granting access based only on IP addresses, users receive permissions based on their job role.

**Example:**

- HR staff → Access HR files only.
- Finance staff → Access financial systems only.
- Guests → Internet access only.

### Key Takeaway

ISE verifies **who you are**, while TrustSec controls **what you can access**.

# **4.3.5 Talk the Talk (Scenario Questions)**

## Question 1

**Blocks or denies traffic based on a positive rule or signature match.**

✅ **Answer:** **IPS (Intrusion Prevention System)**

**Why?**

- Detects malicious traffic.
- Automatically blocks or drops it before damage occurs.   

## Question 2

**A system designed to stop sensitive data from being stolen from or leaving a network.**

✅ **Answer:** **DLP (Data Loss Prevention)**

**Why?**

- Monitors sensitive information.
- Prevents unauthorized transmission of confidential data.

## Question 3

**A system that collects and analyzes security alerts, logs, and historical data from multiple devices.**

✅ **Answer:** **SIEM (Security Information and Event Management)**

**Why?**

- Centralizes logs from many security devices.
- Helps detect and investigate security incidents.

## Question 4

**Scans data against known attack signatures, logs detections, and alerts administrators.**

✅ **Answer:** **IDS (Intrusion Detection System)**

**Why?**

- Detects suspicious activity.
- Generates alerts.
- Does **not** automatically block attacks.
