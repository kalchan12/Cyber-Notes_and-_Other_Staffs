# 3.2.1 What Is Encryption?

**Encryption** is the process of converting readable data (**plaintext**) into an unreadable format (**ciphertext**) so that only authorized users with the correct **key or password** can access it.

Even if someone intercepts encrypted data, they **cannot read it** without the decryption key.

## Why Is Encryption Important?

Encryption helps protect:

- Personal information
- Passwords
- Financial data
- Medical records
- Business documents

**Important:** Encryption protects the **confidentiality** of data, but it **does not stop attackers from stealing or intercepting it.** It only prevents them from understanding its contents.

**Remember:** *Encryption locks the data—it doesn't hide it.*
# 3.2.2 How Do You Encrypt Your Data?

You can encrypt:

- Individual files
- Folders
- Entire hard drives
- USB drives

Encryption software ensures that only authorized users can access the protected data.

## Encrypting File System (EFS)

**Encrypting File System (EFS)** is a Windows feature that encrypts files and folders.

### Key Features

- Built into Windows.
- Linked to a specific user account.
- Only the user who encrypted the data can normally decrypt it.

**Remember:** *EFS protects files even if someone gains access to the computer.*

# 3.2.3 Back Up Your Data

A **backup** is a copy of your important files stored in a separate location.

Backups protect your data from:

- Hardware failure
- Accidental deletion
- Malware
- Ransomware
- Theft

## Good Backup Practices

- Back up your data regularly.
- Store backups on a different device or in the cloud.
- Test backups to ensure they can be restored.

**Remember:** *If your data exists in only one place, it's not really safe.*

# 3.2.4 Are Deleted Files Really Gone?

Deleting a file and emptying the Recycle Bin **does not permanently erase it.**

The operating system simply marks the storage space as **available for reuse**, but the actual data often remains until it is overwritten.

### Scenario Question

**Question:**

After deleting the photos and emptying the Recycle Bin, are they permanently gone?

**Answer:** **No, the photos are just inaccessible from the operating system.**

**Why?**
Data recovery software can often recover deleted files until new data overwrites them.

 

# 3.2.5 Permanently Deleting Data

If you want to permanently remove sensitive data, simply deleting files is **not enough**.

## Secure Deletion Methods

- Use secure erase software that overwrites the data.
- Encrypt the drive before disposal.
- Physically destroy storage devices if necessary.
- Perform a factory reset followed by secure wiping (for supported devices).

These methods help prevent attackers from recovering deleted information.

**Remember:** *Delete removes the reference. Secure erase removes the data.*
