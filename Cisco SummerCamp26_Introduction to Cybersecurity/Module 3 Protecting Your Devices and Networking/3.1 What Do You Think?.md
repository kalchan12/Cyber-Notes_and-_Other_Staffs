# 3.1.1 Securing a New Laptop

When you receive a new laptop, don't start using it immediately. First, secure it.

## Basic Security Steps

- Turn on the **firewall**.
- Install **antivirus and antispyware** software.
- Update the **operating system and web browser**.
- Set a strong **password** or passphrase.

These steps create a basic security foundation before the device is used for work or personal activities.

**Think of it as locking the doors before moving into a new house.**

# 3.1.2 Protecting Your Computing Devices

Your laptop, phone, or tablet contains emails, passwords, documents, photos, and other personal information. Protecting the device helps protect everything stored on it.

## Turn the Firewall On

A firewall monitors network traffic and blocks unauthorized connections.

**Purpose:** Prevent unwanted access to your device.

## Install Antivirus and Antispyware

Security software detects and removes malware such as viruses, spyware, ransomware, and Trojans.

**Purpose:** Protect against malicious software.

## Keep Software Updated

Regularly update:

- Operating system
- Web browser
- Applications
- Security software

Updates often contain security patches that fix newly discovered vulnerabilities.

**Purpose:** Reduce exposure to known attacks.

## Use Password Protection

Protect your device with a strong password, PIN, fingerprint, or facial recognition.

**Purpose:** Prevent unauthorized access if the device is lost or stolen.

# 3.1.3 Wireless Network Security at Home

Your home Wi-Fi network should be secured just like your front door.

## Important Steps

- Change the **default Wi-Fi name (SSID)**.
- Change the **default router password**.
- Enable **WPA2 or WPA3 encryption**.
- Use a strong Wi-Fi password.

Hiding the SSID is **not enough** because attackers can still discover wireless networks.

**Main lesson:** Default settings are known to attackers, so always change them.

# 3.1.4 Public Wi-Fi Risks

Public Wi-Fi in cafes, airports, and hotels is convenient but less secure.

## Risks

- Traffic interception (eavesdropping)
- Fake Wi-Fi hotspots
- Data theft
- Session hijacking

## Safety Tips

- Avoid banking or shopping on public Wi-Fi.
- Turn off file and media sharing.
- Use websites that show **HTTPS**.
- Use a **VPN** whenever possible.

A VPN encrypts your internet traffic, making it much harder for others on the same network to read your data.

**Remember:** Public Wi-Fi should be treated as an untrusted network.

# 3.1.5 Password Security

Your colleague suggests:

- Reusing personal passwords for work accounts.
- Writing passwords in a diary.

This is **poor password security practice**.

### Correct Rating

**1 out of 5 (Bad Practice)**

## Why?

- If one account is compromised, attackers may access other accounts using the same password.
- Written passwords can be lost, stolen, or photographed.

Use **unique passwords** for different accounts and store them in a **password manager** instead of writing them down.

# 3.1.6 A Strong Password

A strong password is difficult for attackers to guess or crack.

## Good Password Characteristics

- At least **12–16 characters**
- Mix of uppercase and lowercase letters
- Numbers
- Special characters
- No personal information
- No common words

### Example

- Weak: `password123`
- Strong: `K7!mQ2#vL9@t`

Longer passwords are usually stronger than short complex ones.

# 3.1.7 Using a Passphrase

A **passphrase** is a sentence or phrase used as a password.

### Example

`AcatTh@tLov3sDogs!`

## Advantages

- Easier to remember
- Longer than most passwords
- Harder to crack with dictionary or brute-force attacks

**Remember:** Long and memorable is often better than short and complicated.

# 3.1.8 Password Guidelines (NIST)

Modern password guidance focuses on **length and uniqueness** rather than forcing complicated rules.

## Recommended Practices

- Use long passwords or passphrases.
- Use a different password for every account.
- Avoid common passwords.
- Enable multi-factor authentication (MFA).
- Change passwords if you suspect compromise.
- Use a password manager.

Frequent forced password changes are generally not recommended unless there is evidence of compromise.

# 3.1.9 Password Check

When evaluating a password, ask:

| Question | Strong Password? |
|---|---|
| Is it long? | Yes |
| Does it avoid common words? | Yes |
| Is it unique? | Yes |
| Does it avoid personal information? | Yes |
| Is it hard to guess? | Yes |

### Quick Examples

| Password | Rating |
|---|---|
| `password` | Weak |
| `John2005` | Weak |
| `Football123` | Weak |
| `BlueTiger!94River` | Strong |
| `CoffeeRain!Window7Tree` | Strong |

**Rule of thumb:** If you can easily guess it, an attacker probably can too.
