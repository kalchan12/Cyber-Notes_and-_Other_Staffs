# 2.1.1 Types of Malware

Malware (malicious software) is any software designed to **damage systems, steal data, gain unauthorized access, or disrupt normal operations.** Each type of malware behaves differently, so recognizing them is important for both prevention and response.

## Spyware

Spyware secretly monitors your activity and collects personal information without your knowledge.

### What it does

- Records keystrokes (keylogging)
- Steals passwords and banking information
- Tracks browsing activity
- Monitors user behavior

**Remember:** Spyware **watches you.**

 

## Adware

Adware automatically displays unwanted advertisements, usually in your web browser.

### What it does

- Shows pop-up ads
- Redirects web pages
- Slows down your device
- May come bundled with spyware

**Remember:** Adware **annoys you with ads.**
## Backdoor

A backdoor is a hidden method that allows attackers to bypass normal authentication and remotely access a system.

### What it does

- Bypasses login security
- Gives attackers remote access
- Runs quietly in the background

**Remember:** A backdoor is a **secret entrance** into a system.
## Ransomware

Ransomware locks or encrypts your files and demands payment to restore access.

### What it does

- Encrypts files
- Locks computers
- Demands a ransom

It commonly spreads through phishing emails or software vulnerabilities.

**Remember:** Ransomware **locks your data for money.**

## Scareware

Scareware tricks users into believing their computer is infected to convince them to install fake software.

### What it does

- Displays fake security warnings
- Creates panic
- Tricks users into downloading malware

**Remember:** Scareware **scares you into infecting yourself.**

## Rootkit

A rootkit hides itself deep within the operating system, allowing attackers to maintain privileged access while avoiding detection.

### What it does

- Creates hidden backdoors
- Hides malicious activities
- Modifies system files
- Very difficult to detect and remove

**Remember:** Rootkits **hide attackers inside your system.**

## Virus

A virus attaches itself to legitimate files and spreads when those files are executed.

### What it does

- Infects other files
- Requires user action to spread
- Can damage or delete data

Commonly spreads through USB drives, email attachments, and downloaded files.

**Remember:** A virus **needs a host file** to spread.

## Trojan Horse

A Trojan disguises itself as legitimate software but secretly performs malicious actions.

### What it does

- Pretends to be safe
- Installs malware
- Steals data
- Opens backdoors

Unlike viruses, Trojans **do not replicate themselves.**

**Remember:** A Trojan **looks safe but isn't.**
## Worm

A worm is self-replicating malware that spreads automatically across networks without user interaction.

### What it does

- Spreads by itself
- Exploits system vulnerabilities
- Infects multiple computers quickly
- Can overload networks

**Remember:** Worms **don't need a host or user action—they spread on their own.**

# Quick Comparison

| Malware | Main Purpose |
| -------|--------------|
| Spyware | Steals information by spying on users |
| Adware | Displays unwanted advertisements |
| Backdoor | Provides hidden remote access |
| Ransomware | Encrypts files for ransom |
| Scareware | Tricks users with fake security alerts |
| Rootkit | Hides malware and gives privileged access |
| Virus | Infects other files and spreads with user action |
| Trojan Horse | Disguises itself as legitimate software |
| Worm | Self-replicates and spreads automatically |



# 2.1.2 Symptoms of Malware

Malware often leaves warning signs before it is discovered. If your device suddenly behaves strangely, malware could be the cause.

## Common Symptoms

- Slow computer performance.
- Frequent crashes or freezing.
- Unexpected pop-up advertisements.
- Programs opening or closing by themselves.
- Unknown software installed.
- Browser homepage or search engine changes unexpectedly.
- Files become missing, corrupted, or encrypted.
- Unusual network or internet activity.
- Antivirus software becomes disabled.
- High CPU, memory, or disk usage without explanation.
