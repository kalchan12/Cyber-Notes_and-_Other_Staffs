
## 3.0.1 Advanced Search with a Web Browser

### Understanding Search Engines
* **Role of Search Engines:** Specialized web services designed to index the internet and retrieve relevant web pages, documents, and media based on text queries entered by the user.
* **Default Search Engine:** Web browsers come pre-configured with a default search engine (e.g., Google, Bing, DuckDuckGo). Users can type queries directly into the browser's address bar (omnibox).
* **Customizing the Default Search Engine:**
  * Access the browser settings menu (**Settings** $\rightarrow$ **Search engine**).
  * Select your preferred provider from the available list or add custom search engines.
* **Basic Search Workflow:**
  1. Enter relevant keywords into the address bar or search engine input field.
  2. Press `Enter` (desktop) or tap `Go` / `Search` (mobile).
  3. Review the ranked search engine results page (SERP) containing webpage titles, URLs, and descriptive snippets.
* **Filtering by Content Category:** Refine results by switching tabs at the top of the search results page:
  * **All:** Comprehensive search across all indexed formats.
  * **Images:** Visual assets and photo galleries.
  * **Videos:** Video clips and streaming tutorials.
  * **News:** Current articles from recognized news publishers.
  * **Shopping:** Product listings, pricing, and vendor options.
  * **Maps:** Geographical directions, local business listings, and reviews.

### Advanced Search Operators
Using precision search operators allows users to filter through vast amounts of information and isolate exact resources quickly:

| Operator | Syntax Example | Function & Purpose |
| :--- | :--- | :--- |
| **Quotation Marks** | `"digital literacy"` | **Exact Phrase Matching:** Forces the search engine to return only pages containing that exact phrase in the specified order. |
| **Minus Sign (Hyphen)** | `jaguar -car` | **Exclusion Operator:** Removes results containing a specific keyword. Invaluable for eliminating ambiguity or unwanted clutter. |
| **Site Filter** | `site:edu cybersecurity` | **Domain/Site Restriction:** Limits search results exclusively to a specified website or top-level domain (e.g., `.gov`, `.edu`, `cisco.com`). |
| **Filetype Filter** | `network basics filetype:pdf` | **Document Type Targeting:** Finds downloadable files in specific formats (e.g., `pdf`, `ppt`, `docx`, `xlsx`). |
| **Time Frame Filter** | Search Tools $\rightarrow$ Any time | **Temporal Filtering:** Restricts results to specific date ranges (e.g., past hour, past 24 hours, past week, past year) to locate the freshest data. |

> [!TIP]
> **Combining Search Operators:** You can combine multiple search operators in a single query for maximum precision. For example, `"cloud computing" site:edu filetype:pdf` will only return PDF documents discussing cloud computing published on educational institution websites.

## 3.0.2 Evaluating Search Results: Quality and Safety

Not every search result is safe, accurate, or relevant. Navigating search engines effectively requires critical discernment:

### Identifying Relevant Results
* **Direct Answer to Intent:** Matches the specific informational, transactional, or navigational purpose of your query.
* **Source Credibility & Authority:** Published by established organizations, academic bodies, peer-reviewed journals, or recognized industry experts.
* **Currency:** Contains recently updated data, especially critical for technical topics, legal standards, and news.

### Spotting Irrelevant & Misleading Results
* **Keyword Stuffing & SEO Manipulation:** Pages engineered purely to rank high on search algorithms without providing meaningful substance.
* **Clickbait Headlines & Misleading Meta Descriptions:** Titles designed to provoke curiosity or emotional reactions that fail to deliver relevant answers once clicked.
* **Superficial Coverage:** Content that only peripherally touches on the topic while driving ad impressions or affiliate sales.

### Avoiding Malicious Results
* **Typosquatting & Impersonation Domains:** Deceptive URLs mimicking legitimate organizations (e.g., misspelling bank or institutional web addresses) to harvest credentials.
* **Drive-By Downloads:** Sites that trigger immediate file downloads upon entry. Never open or execute unverified files.
* **Browser Security Alerts:** Modern browsers issue warnings when an SSL/TLS certificate is missing/invalid or a site has been flagged for phishing. Always heed these warnings and exit immediately.

### Best Practices for Safe Searching
* **Critically Examine the URL:** Inspect the full web address before clicking to ensure it leads to the legitimate domain.
* **Leverage Security Tools:** Utilize reputable ad-blocking and anti-tracking extensions, browser protection filters, and active antivirus software.
* **Cross-Reference Claims:** Never rely on a single obscure source for critical facts or advice.

## 3.0.3 Searching Within a Webpage or Document

Locating specific words or sections within long articles, PDFs, or software documents can be done instantly using built-in search tools:

### Method 1: Application Menu Bar
1. Navigate to the top application menu bar (commonly structured as **File**, **Edit**, **View**, **Tools**, **Help**).
2. Click **Edit** and look for **Find** or **Search**.
3. A search bar or pop-up box will appear (typically in the upper-right or lower-left corner).
4. Type your query keyword and press `Enter`.
5. The application will highlight all matching occurrences and indicate the total match count (e.g., `1 of 12`).
6. **Find and Replace Feature:** Many office applications (e.g., Word, Google Docs) offer an advanced **Replace** tool under Edit to swap recurring words across the document automatically.

### Method 2: Keyboard Shortcuts
Keyboard shortcuts streamline repetitive tasks and save substantial time:

* **Windows & Linux:** `Ctrl + F`
* **macOS:** `Cmd + F` (`⌘ + F`)
* **Workflow:** Press and hold `Ctrl` or `Cmd`, tap `F`, then release both keys. Enter your search text immediately into the prompt that appears. Use `Enter` or the arrow keys to cycle through matches.

# 3.1 Navigating the Internet

## 3.1.1 Hyperlinks, Browser Controls, and Cookies

### Hyperlinks (Links)
* **Visual Characteristics:** Hyperlinks connect web resources across the global network. They are typically styled with distinct colors (traditionally blue), underlines, or interactive button styling.
* **Hover State:** Moving the mouse cursor over a hyperlink changes the pointer from a standard arrow to a pointer hand icon.
* **Browser History Navigation:**
  * **Back Button:** Returns to the immediately preceding page in the browsing history.
  * **Forward Button:** Moves forward to the page visited before pressing Back.
  * **Refresh / Reload (`F5` or `Ctrl + R`):** Re-fetches and re-renders the current page to display updated content.

### Cookies: Definition and Operational Role
* **Definition:** Cookies are small text files placed on your local device (computer, smartphone, or tablet) by websites you visit.
* **Purpose:** Act as digital memory tags that allow websites to recognize returning visitors and retain state across web sessions.

### Primary Functions of Cookies
* **Session & Preference Management:**
  * Remembers account login sessions so users do not have to authenticate on every subpage.
  * Retains interface configurations (e.g., dark mode vs. light mode, preferred language, display layout).
  * *Analogy:* A regular patron visiting a neighborhood café where the barista immediately knows their favorite order.
* **Analytics and Personalization:**
  * Tracks pages viewed, duration of visit, and navigation paths to optimize website architecture and suggest relevant content.
  * *Analogy:* A bookseller recommending related literature based on your past inquiries.
* **E-Commerce Shopping Carts:**
  * Preserves items added to an online cart as you browse different categories. Without cookies, the cart would reset on each click.
* **Advertising and Cross-Site Tracking:**
  * Third-party tracking cookies follow user activity across disparate websites to build behavioral profiles and serve targeted advertisements.
  * *Analogy:* An advertising scout following you throughout a shopping mall, recording every product examined and whether you made a purchase.

### Privacy Regulations and Cookie Consent
* **Consent Banners:** Regulations such as the General Data Protection Regulation (GDPR) and California Consumer Privacy Act (CCPA) require websites to disclose cookie usage and request user consent upon the first visit.
* **User Control Options:**
  * **Accept All:** Grants permission for functional, analytical, and marketing cookies.
  * **Customize / Manage Preferences:** Allows users to enable strictly necessary functional cookies while disabling marketing and advertising trackers.
  * **Reject Non-Essential:** Declines all non-mandatory tracking mechanisms. Most legitimate sites maintain full readability even when tracking cookies are rejected.
  * **Browser Management:** Modern browsers offer native tools to block third-party cookies, clear cookies upon browser exit, or delete site data manually.

## 3.1.2 Bookmarks: Organizing and Managing Web Resources

### Purpose of Bookmarks
Bookmarks (or "Favorites") allow users to store and categorize web addresses (URLs) locally in the browser, enabling quick one-click access without memorizing complex URLs or performing repeated searches.

### Creating Bookmarks Across Devices
* **Desktop Browsers (e.g., Google Chrome):**
  1. Navigate to the desired website (e.g., `https://www.wikipedia.org`).
  2. Click the **Star icon** located on the far right of the address bar (or press `Ctrl + D` on Windows/Linux, `Cmd + D` on macOS).
  3. Select **Done** to save with the default page title, or click **Edit** to customize the bookmark name and specify a storage folder.
* **Mobile Devices (Android Chrome):**
  1. Open the website.
  2. Tap the **three-dot menu icon** (`⋮`) in the upper-right corner.
  3. Tap the **Star icon** to save. Tap again to edit the name or change the destination folder.

### Managing and Organizing Bookmarks
* **Bookmarks Bar:** A horizontal bar beneath the address bar for storing high-frequency links for instant one-click access.
* **Folder Hierarchy:** Create categorized folders (e.g., *Work*, *Research*, *Finance*, *Entertainment*) to prevent clutter and maintain organized archives.
* **Editing & Deleting:**
  * *Desktop:* Right-click the bookmark on the bar or open the **Bookmark Manager** (`Ctrl + Shift + O`), then select **Edit** or **Delete**.
  * *Mobile:* Open the browser menu $\rightarrow$ **Bookmarks**, tap the three dots beside the target bookmark, and select **Delete**.

# 3.2 Who Owns What on the Internet

## 3.2.1 Copyright, Licensing, and Digital Ownership

### Intellectual Property (IP)
* **Definition:** Creations of the human mind, including literary works, musical compositions, artistic designs, computer software, and recipes.
* **Core Principle:** Just as physical property (a vehicle or a home) belongs to its owner and cannot be used without consent, intellectual property belongs to its creator, who holds the legal right to decide how it is used, shared, and monetized.

### Traditional Copyright
* **Automatic Protection:** Automatically attaches to original creative works the moment they are fixed in a tangible medium of expression (written down, recorded, programmed, or drawn).
* **Exclusive Rights:** The author holds exclusive authority over reproduction, distribution, public performance, display, and creation of derivative works.
* **The Digital Replication Dilemma:**
  * *Physical World:* Lending a physical book to a friend transfers the single physical object; the original lender no longer has access until it is returned.
  * *Digital World:* Sharing an e-book or digital file creates an identical duplicate at virtually zero cost. The author receives no compensation or royalties for unauthorized copies.
* **Digital Rights Management (DRM):** Technological access control mechanisms implemented by software developers and media distributors (e.g., Amazon Kindle, streaming services) to prevent unauthorized copying, export, or redistribution of copyrighted content.

### Creative Commons (CC) Licenses
Creative Commons licenses provide a flexible legal framework for creators who wish to share their works publicly while retaining copyright and establishing specific conditions for reuse:

| License Type | Symbol / Acronym | Conditions & Permissions |
| :--- | :--- | :--- |
| **Attribution** | `CC BY` | Most permissive license. Allows sharing and adapting, even commercially, provided the original creator is properly credited. |
| **Attribution-ShareAlike** | `CC BY-SA` | Permits sharing and remixing, even commercially, as long as credit is given and derivative works are licensed under identical terms. |
| **Attribution-NonCommercial** | `CC BY-NC` | Permits sharing and remixing for non-commercial purposes only, with mandatory attribution. |
| **Attribution-NonCommercial-NoDerivatives** | `CC BY-NC-ND` | Most restrictive standard license. Allows others to download and share the work with credit, but prohibits modifying the content or using it commercially. |

### Public Domain
Works in the public domain are free of intellectual property restrictions and may be used, modified, and built upon by anyone for any purpose without permission or royalties.

* **Paths to the Public Domain:**
  1. **Copyright Expiration:** Legal copyright terms eventually expire (e.g., classical compositions, historical literature).
     * *Example:* The original literary version of A.A. Milne's *Winnie-the-Pooh* entered the public domain in 2022, allowing new adaptations; however, Disney's later stylized animations remain strictly protected by copyright.
     * *Musical Distinction:* Beethoven's Fifth Symphony musical score is in the public domain, but a contemporary orchestral audio recording of that symphony possesses separate copyright held by the recording orchestra and producer.
  2. **Government Works:** Publications, photographs, and data generated by certain governments (e.g., US Federal Government agencies) are automatically placed into the public domain.
  3. **Voluntary Dedication:** Creators can formally relinquish all copyright by releasing works under declarations like `CC0` (Creative Commons Zero).
* **Key Implication:** Once dedicated to the public domain, creators hold no control over secondary usage and cannot claim royalties if third parties incorporate the work into commercial products.

### Fair Use and Fair Dealing
* **Purpose:** Legal doctrines (known as **Fair Use** in the United States and **Fair Dealing** in UK/Commonwealth jurisdictions) that permit limited, unauthorized use of copyrighted material to advance public discourse, education, and creativity.
* **Permitted Applications:**
  * Academic teaching and classroom instruction.
  * Critical commentary, analysis, and reviews (e.g., quoting a book excerpt or showing brief film snippets in a review).
  * News reporting and journalism.
  * Scientific scholarship and research.
* **Practical Guidelines:**
  * Proportion matters: borrowed portions must be limited and directly relevant to the commentary (a common practical guideline is that copyrighted material should represent a minimal fraction—often under 10%—of the new work).
  * Market impact: the derivative work should not serve as a market substitute that deprives the original creator of revenue.
  * For major commercial endeavors, consulting legal counsel is strongly advised.

### Software Copyright and Open Source
* **Proprietary Code:** Computer software, compiled binaries, and source code are protected under copyright law. Rebranding proprietary software (e.g., copying Microsoft Office code, replacing logos, and selling it) is illegal copyright infringement.
* **Open Source Software (OSS):** Developers intentionally publish source code under open licenses (e.g., MIT, GNU General Public License, Apache), permitting others to study, modify, improve, and redistribute the software collaboratively.

## 3.2.2 Citing Sources and Academic Integrity

Maintaining thorough records of digital resources and properly citing them ensures academic honesty, supports fact-checking, and prevents plagiarism.

### Citation Systems
Academic and professional works use standardized bibliographic systems, including **Harvard**, **APA**, **MLA**, and **Chicago**. Each system defines precise formatting guidelines for online media.

### Key Elements of Digital Citations
When citing online sources, record the following six core elements:
1. **Authorship:** Name of the individual author. If published by an institution or corporation, cite the organization name. If no author is credited, begin directly with the document title.
2. **Year of Publication:** The year the content was published or last revised. If unavailable, use `n.d.` ("no date").
3. **Title of Article / Webpage:** Italicize the title of the specific document or webpage.
4. **Website / Publisher Name:** Include the name of the website if it differs from the corporate author.
5. **URL (Uniform Resource Locator):** Provide the complete, functional web link directing readers to the specific resource.
6. **Access Date:** The specific date you viewed the page. Essential for digital media because web content frequently updates, moves, or gets archived.

### Standard Citation Example (Harvard Style)
```text
Johnson, A. (2021). The Impact of Climate Change on Marine Biodiversity. Environmental Studies Portal. Available at: https://www.environmentalstudiesportal.org/articles/climate-change-marine-biodiversity (Accessed: 18 March 2024).
```
