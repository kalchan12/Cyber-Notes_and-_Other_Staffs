# Module 2: You Will Need Some Basic Tools

## 2.0 Hardware, Software, and System Basics

### 2.0.1 Foundational Components

To accomplish tasks in the digital world, every activity relies on a hierarchy of hardware, operating systems, and applications.

#### Software Hierarchy
* **Operating System (OS):**
  * The essential software that enables device operation.
  * Provides a Graphical User Interface (GUI) for visual navigation and interaction.
  * Manages hardware resources, runs background processes, configures system settings, and provides file management.
  * *Common Operating Systems:*
    * **Windows (Microsoft):** Dominant OS for personal and business computers.
    * **Android (Google):** Most widespread OS for smartphones and tablets.
    * **macOS & iOS (Apple):** Operating systems tailored for Mac computers and iPhones/iPads.
    * **Linux:** Open-source OS popular among programmers and system administrators (steeper learning curve for beginners).
* **Applications & Programs:**
  * Specialized tools that run on top of the OS to perform specific functions (e.g., web browsers, text editors, media players, office suites).
  * While many apps work across both desktop and mobile platforms, desktop environments offer better ergonomics and efficiency for complex tasks like word processing and data analysis.

---

### 2.0.2 Input and Output Devices

Computer hardware relies on peripheral devices to receive and present data:

* **Input Devices (Data in):** Tools used to input information and commands into the computer.
  * Keyboards, mice, touchpads, microphones, webcams.
* **Output Devices (Data out):** Peripherals that transmit processed information to the user.
  * Monitors/displays, external speakers, headphones, printers.
* **Laptops vs. Desktops:**
  * *Laptops* integrate all essential components (monitor, keyboard, speakers, microphone, touchpad) into a portable chassis.
  * *Ergonomic Setups:* Using external monitors at eye level alongside external keyboards and mice significantly reduces physical strain during extended work sessions.

---

### 2.0.3 Device Connectivity: Wired vs. Wireless

Peripherals connect to systems through physical cables or wireless signals:

| Connection Type | Standard | Purpose & Characteristics |
| :--- | :--- | :--- |
| **Wired** | **USB (Universal Serial Bus)** | Connects standard peripherals (keyboards, mice, flash drives, external hard drives). |
| **Wired** | **HDMI (High-Definition Multimedia Interface)** | Transmits high-definition audio and video signals to monitors and projectors. |
| **Wireless** | **USB Wireless Dongle (RF 2.4GHz)** | Small plug inserted into a USB port that communicates wirelessly with the peripheral. |
| **Wireless** | **Bluetooth** | Short-range wireless standard (~10 meters / 30 feet) allowing direct pairing without dongles (e.g., wireless headphones, Bluetooth keyboards for tablets). |

> [!TIP]
> **Troubleshooting Wireless Peripherals:** Wireless devices rely on internal batteries. If a wireless mouse or keyboard becomes unresponsive, checking and replacing/recharging the battery is the first troubleshooting step.

---

### 2.0.4 Navigating Operating System Interfaces

#### Windows Interface
* **Taskbar:** Located along the bottom of the screen; houses the Start menu, pinned shortcut icons, and currently running application windows.
* **System Tray (Notification Area):** Bottom-right corner displaying:
  * Clock and expandable calendar.
  * Battery status, volume level, and network/Wi-Fi connection.
  * Quick settings menu (screen brightness, airplane mode, Bluetooth toggles).
  * Cogwheel icon for full system settings.
* **File Explorer:** Launched via the folder icon; provides complete visibility into internal/external drive capacities, directory trees, and stored files.

#### Android Interface
* **Notification & Quick Settings Shade:** Accessed by swiping down from the top of the display.
  * *First Swipe:* Displays incoming notifications and primary quick toggles (Wi-Fi, Bluetooth, flashlight).
  * *Second Swipe:* Expands the full quick-settings grid, screen brightness slider, and additional setting tiles.
  * *Gear / Cogwheel Icon:* Grants full access to device configuration settings.

## 2.1 Performing Everyday Tasks

### 2.1.1 File Management and Organization

#### Anatomy of File Explorer
* **Top Bar:** Active tab name, new tab button (`+`), and window control buttons (Minimize, Maximize/Restore, Close).
* **Navigation Bar:** Back, forward, and up navigation buttons, breadcrumb address bar (current file path), and search bar.
* **Navigation Pane (Left Column):** Quick access directory tree (Desktop, Documents, Downloads, external drives, network locations).
* **Main Display:** Contents of the selected directory.

#### Files, Folders, and Storage Principles
* **Files:** Every discrete digital item created or saved (documents, photos, audio tracks, spreadsheets) is a file stored on the local hard drive / SSD.
* **Folders (Directories):** Organizational containers used to group related files logically.
* **Desktop Organization:** While convenient as a temporary holding area, storing all files directly on the desktop leads to clutter and difficulty locating items. Structured directory trees prevent disorganization.

#### Creating, Renaming, and Organizing Files
1. **Create a Folder:** Right-click inside empty space $\rightarrow$ Select **New** $\rightarrow$ Click **Folder**.
2. **Naming & Renaming:** Right-click the folder or file $\rightarrow$ Select **Rename** (or press `F2`).
3. **Descriptive Naming Convention:**
   * Files in directories display only metadata by default: name, file extension/type, size, and date modified.
   * Clear, descriptive filenames eliminate the need to open every file to identify its contents, much like titles on book spines in a library.
4. **Search Functionality:** Use the search bar in the top-right corner of File Explorer to query filenames or keywords within a specific folder or across the entire drive.

## 2.2 Security and Password Hygiene

### 2.2.1 Device Authentication and Locking Methods

Devices and accounts can be secured through multiple layers:
* **Passwords & Passphrases:** Alphanumeric character combinations.
* **PIN Codes:** Short numeric strings (typically 4–6 digits).
* **Pattern Locks:** Predetermined grid paths drawn on touchscreen displays.
* **Biometric Authentication:** Biological identifiers such as fingerprint scanners or facial recognition cameras.

---

### 2.2.2 Password Construction: Types and Security Analysis

Understanding password construction methods helps in evaluating security versus usability:

| # | Password Type | Description | Vulnerability / Security Assessment |
| :---: | :--- | :--- | :--- |
| **1** | **Dictionary Words** | Single words commonly found in dictionaries (e.g., `apple`, `password`). | **Very Weak:** Susceptible to automated dictionary attacks that test thousands of words per second. |
| **2** | **Alphanumeric** | Combines letters and numbers (e.g., `Sun7Day`). | **Moderate:** Stronger than pure dictionary words, but vulnerable if common number sequences (e.g., `123`) are used. |
| **3** | **Symbol Inclusion** | Integrates special characters (`!@#$%^&*()`). | **Good:** Increases entropy; avoid predictable patterns like placing exclamation marks only at the very end. |
| **4** | **Passphrases** | Multi-word phrases or full sentences (e.g., `the-blue-river-runs-fast`). | **Strong:** Length provides high mathematical resistance to cracking. Adding symbols and numbers further strengthens it. |
| **5** | **Sequential Numbers** | Digits arranged in linear sequence (e.g., `12345`). | **Extremely Weak:** Among the very first combinations attempted by attackers. |
| **6** | **Random Letters** | Unstructured assortment of uppercase and lowercase letters. | **Strong:** High unpredictability, but harder for humans to memorize without a password manager. |
| **7** | **Leetspeak** | Replacing letters with lookalike numbers or symbols (e.g., `pa55w0rd`, `h0u$e`). | **Weak to Moderate:** Attackers' dictionaries automate predictable substitutions (`0` for `o`, `1` for `l`, `@` for `a`). |
| **8** | **Abbreviations (Acronyms & Initialisms)** | Taking the first letter of each word in a memorable sentence (e.g., *My dog has four white paws!* $\rightarrow$ `Mdh4wp!`). | **Strong & Memorable:** Easy to recall while appearing random to cracking tools. Avoid famous quotes or public song lyrics. |
| **9** | **Pattern-Based** | Tracing physical keyboard paths (e.g., `qwerty`, `asdfgh`). | **Very Weak:** Readily detected by automated pattern-recognition cracking scripts. |
| **10** | **Personal Information** | Incorporating birthdays, pet names, or family details. | **Unsafe:** Information is easily discovered through basic Open Source Intelligence (OSINT) or social media. |
| **11** | **Mixed Category** | Combining passphrases, acronyms, mixed cases, numbers, and symbols. | **Highly Recommended:** Maximizes length, complexity, and unpredictability while remaining usable. |
| **12** | **System-Generated** | Random string produced by an algorithmic generator (e.g., via password managers). | **Maximum Entropy:** Completely removes human cognitive bias and predictability. |
| **13** | **Memorable Dates (Disguised)** | Significant dates transformed into non-standard, obfuscated formats. | **Moderate to Strong:** Retains personal recall while obscuring standard date patterns. |
| **14** | **PIN (Personal Identification Number)** | Short sequence of digits primarily used for rapid unlocking and banking. | **Convenient:** Useful for local device unlocking; avoid birthdays and repetitive digits (e.g., `0000`, `1111`). |
| **15** | **Biometrics** | Physical identification via fingerprints, retina scans, or facial recognition. | **High Local Security:** Tied directly to physical traits, eliminating the need to type or memorize credentials. |

---

### 2.2.3 Core Principles of Password Hygiene

* **Length is Critical:** Password length exponentially increases cracking time. A long passphrase is significantly stronger than a short, complex password.
* **Avoid Predictability:** Steer clear of common substitutions, keyboard walks (`12345`, `qwerty`), and public personal details.
* **Multi-Factor Authentication (MFA):** Complement strong credentials with multi-factor authentication (e.g., authenticator apps, security keys) whenever available.
